# persuasio 0.1.0

* Initial CRAN submission.
* Provides functions for estimation and inference on average and local
  persuasion rates.
* Supports data scenarios with binary outcomes, treatments, and instruments,
  as well as cases where only the outcome and instrument are observed.
* Includes functions for calculating bounds from summary statistics.
* Includes the Gerber, Karlan, and Bergan example dataset.
